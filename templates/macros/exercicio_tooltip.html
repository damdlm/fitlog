{# Macro: tooltip_nome_exercicio ------------------------------ Monta o texto (para dentro de um atributo title) do tooltip do card de seleção de exercício: nome/descrição na primeira linha e, se houver, a lista de nicknames (ExercicioSistema.nicknames) nas linhas seguintes. Texto puro (com quebras de linha reais via \n), não HTML -- o atributo title nativo do navegador já quebra linha em \n sozinho, então isso funciona tanto com o tooltip custom do Bootstrap (que também respeita \n via white-space: pre-line, ver .etv-tooltip-nomes no CSS) quanto no tooltip nativo do navegador como fallback, sem risco de mostrar tags HTML cruas caso o JS do tooltip não rode por algum motivo. Uso: {% from "macros/exercicio_tooltip.html" import tooltip_nome_exercicio %}
{{ ex.nome }}
#} {%- macro tooltip_nome_exercicio(ex) -%} {%- set titulo = ex.descricao or ex.nome -%} {%- set apelidos = ex.nicknames if ex.nicknames else [] -%} {%- set linhas = [titulo] -%} {%- if apelidos -%} {%- set _ = linhas.append('Outros nomes:') -%} {%- for apelido in apelidos -%} {%- set _ = linhas.append('• ' ~ apelido) -%} {%- endfor -%} {%- endif -%} {{- linhas|join('\n') -}} {%- endmacro -%}
